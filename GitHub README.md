# E-Commerce Customer Purchase Analysis and Product Recommendation System

## Project Overview

This project analyzes customer purchase behavior using Big Data technologies such as Hadoop, Hive, and Pig.

The system processes e-commerce transaction data, performs data preprocessing, analyzes customer purchasing behavior, identifies frequently purchased products, and generates simple product recommendations.

## Objective

- Store e-commerce transaction data in HDFS
- Clean and preprocess data using Pig
- Analyze purchase trends using HiveQL
- Identify frequently bought-together products
- Generate product recommendations
- Perform customer behavior analysis
- Segment customers based on purchasing behavior
- Evaluate recommendation effectiveness

## Dataset

The dataset contains the following columns:

- Transaction_ID
- Customer_ID
- Transaction_Date
- Product_ID
- Product_Name
- Category
- Quantity
- Unit_Price
- Total_Amount
- Payment_Method
- City
- Device_Type
- Customer_Rating
