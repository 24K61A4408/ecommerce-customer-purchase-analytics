# Project Notes

## Project

**E-Commerce Customer Purchase Analytics**

## Objective

Develop a big data processing workflow to analyze customer purchase behavior, identify sales and purchase trends, and generate simple product recommendations using Hadoop HDFS, Apache Pig, and Apache Hive.

## Dataset Details

**Total input records:** 203

**Duplicate records:** 3

**Cleaned records:** 200

**Total customers:** 49

**Total products:** 15

**Total categories:** 4

The dataset contains the following fields:

1. Transaction_ID
2. Customer_ID
3. Transaction_Date
4. Product_ID
5. Product_Name
6. Category
7. Quantity
8. Unit_Price
9. Total_Amount
10. Payment_Method
11. City
12. Device_Type
13. Customer_Rating

The dataset contains e-commerce transactions from **January 2026 to August 2026**.

## Data Processing

### HDFS

The original CSV dataset was uploaded to:

`/ecommerce/input/`

The cleaned dataset generated by Pig was stored in:

`/ecommerce/cleaned/`

### Pig

Pig was used to:

* Load the CSV dataset
* Remove duplicate records
* Generate the cleaned dataset

**Input records:** 203
**Duplicate records:** 3
**Cleaned records:** 200

No missing values were found in the dataset.

### Hive

Hive was used for:

* Creating the e-commerce database
* Creating transaction tables
* Loading cleaned data
* Counting records
* Sales analysis
* Category analysis
* Product analysis
* Customer analysis
* City analysis
* Payment method analysis
* Monthly purchase trend analysis
* Product recommendation analysis

## Product Recommendation

Product recommendation can be generated by analyzing the purchase history of customers and identifying products purchased by the same customers.

The recommendation workflow is:

Customer Purchase History
↓
Analyze Previous Purchases
↓
Identify Related Products
↓
Generate Product Recommendations

## Final Outcome

The project successfully demonstrates an end-to-end e-commerce customer purchase analytics workflow using **Hadoop HDFS, Apache Pig, and Apache Hive**.

The dataset was cleaned by removing duplicate records, and the cleaned data was used to analyze customer purchases, product sales, categories, cities, payment methods, and monthly trends. The analysis provides a foundation for generating simple product recommendations based on customer purchase history.
